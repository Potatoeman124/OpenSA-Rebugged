# OSArB 1.1 - inherited-content release exception

The project maintainer explicitly authorized upstream-equivalent risk acceptance for this release: preserve the audit and attribution, acknowledge that rights remain unresolved, but permit existing inherited OpenSA content under a documented exception.

This is a project release decision, not a license grant, rights-holder permission, or a declaration that the content is public domain. Original creators retain their rights. The non-commercial upstream OpenSA distribution approach is the stated basis for the maintainer's decision.

Scope: OSArB 1.1 only, for the exact existing files recorded in `assets/provenance/release-1.1-exception.json` in the source distribution. That snapshot includes the inherited media and maps present in the audited reBugged tree, including existing adaptations. Changed or newly added assets are not automatically covered. The September 2026 audit and all original credits remain available. Explicitly licensed sounds retain the terms in ASSET_ATTRIBUTIONS.md.

The eight original Swarm Assault Game/Start ANI, DDF, MIN and SDF bundles are excluded. Players must supply their own original installation and import its verified assets locally. This exception does not enable remote asset downloads.
