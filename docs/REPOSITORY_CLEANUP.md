# Repository cleanup after the OSArB 1.1 overlay switch

The release path is now **OpenSA: Build Overlay ZIP** in VS Code, or `build-pipeline.cmd overlay`. This cleanup removes abandoned packaging and generated working files. It does not change game code, maps, rules, RMG profiles, historical generator compatibility, or the overlay baseline.

## Tracked files

Removed 22 obsolete tracked files:

- Windows installer and full portable-package builders.
- The tag-triggered native release workflow and the experimental AppImage/DMG artifact workflow.
- Their platform packaging scripts, NSIS installer definition, common packaging helper, and 11 installer-only artwork files.
- The per-user Rider/ReSharper solution settings file; future `*.DotSettings.user` files are ignored.

Removed the unused `portable` command, architecture argument, installer configuration variables, and packaging-script checks from the build entry points. Source compilation, validation, local asset import, and the VS Code overlay task remain available. The CI workflow still checks source builds; it no longer references removed packaging scripts. The asset audit, attribution, license, and exact-file release exception remain preserved as historical evidence. Removing unused artwork does not rewrite that history.

## Local generated files

The initial removal pass deleted **130,200 files (11.729 GiB)** from explicitly checked paths inside the workspace:

- Old installers, standalone archives, extracted test installations and package staging trees.
- NSIS, downloaded SDK/installer archives, and the duplicate SDK under `engine/.dotnet`; the active `.tools/dotnet` SDK and NuGet cache remain.
- Stale project build intermediates, regenerated by the subsequent verification build.
- Bulk RMG per-case generated maps, debug exports and native terrain buffers, temporary implementation scripts/assemblies, and early phase-zero UI captures.

Kept the current overlay ZIP/checksum in `artifacts`, the source engine, active build tools, original handoff archives and their inputs, provenance records, aggregate test matrices/results, comparison galleries, and runtime validation evidence. In particular, 79 RMG `verification.json` summaries and the two handoff ZIPs remain. Older documentation may name individual generated cases that have now been removed; regenerate those cases from retained settings and the documented tooling when needed.

All deletion targets were resolved inside the workspace and checked for reparse points before removal. No files in the installed OpenSA directory or external asset storage were part of the cleanup. The exact local deletion inventory is `artifacts/cleanup-20260927/untracked-removal-plan.json`; completion totals are in `removal-result.json`.
